⚠️ Brskalnik Ni Podprt

Ta aplikacija potrebuje File System Access API, ki je na voljo le v brskalnikih Chrome ali Edge.

Prosimo, odprite to aplikacijo v enem od naslednjih brskalnikov:

  • ✅ Google Chrome (različica 86 ali novejša)
  • ✅ Microsoft Edge (različica 86 ali novejša)

Firefox, Safari in drugi brskalniki niso podprti zaradi pomanjkanja dostopa do datotečnega sistema.
